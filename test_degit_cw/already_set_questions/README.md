## ⚡ How to Run Any Question

Run from the root directory:
```bash
# Example: Run Question 1
npm run q1

# Example: Run Question 5
npm run q5

# Run all 10 solutions simultaneously
npm run all
```

Or navigate to any specific question folder:
```bash
cd already_set_questions/Q1_Book_Ecommerce_Roll_24-30
npm start
```
Open **`http://localhost:<PORT>`** in your browser.
